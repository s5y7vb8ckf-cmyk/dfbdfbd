للتشغيل من جهازك، افتح MiloCashier.html في المتصفح وسجّل الدخول بحساب المتجر. رابط الخدمة مضمن في الصفحة. عند انقطاع الشبكة يحفظ الكاشير الفواتير والورديات والإعدادات على الجهاز، ثم يزامنها تلقائيًا عند عودة الاتصال.

للتركيب داخل Apps Script كخيار آخر:
تركيب واجهة الكاشير على مشروع Apps Script الحالي

الملف MiloCashier.html هو واجهة البيع. أضفه إلى مشروع Apps Script كملف HTML بالاسم MiloCashier (من دون كتابة الامتداد في اسم الملف).

في ملف Code.gs، استبدل دالة doGet الحالية بهذه النسخة. أبقِ بقية كود قاعدة البيانات كما هو:

function doGet(e){
  if(e && e.parameter && String(e.parameter.cashier||'')==='1'){
    return HtmlService.createHtmlOutputFromFile('MiloCashier')
      .addMetaTag('viewport','width=device-width, initial-scale=1, viewport-fit=cover')
      .setTitle('MILO | الكاشير');
  }
  if(e && e.parameter && String(e.parameter.mobile||'')==='1'){
    return HtmlService.createHtmlOutputFromFile('MiloMobile')
      .addMetaTag('viewport','width=device-width, initial-scale=1, viewport-fit=cover')
      .setTitle('MILO | موقع الجوال');
  }
  return ContentService.createTextOutput('Milo Cashier cloud is running');
}

بعد الحفظ، انشر المشروع كتطبيق ويب أو حدّث النشر الحالي، ثم افتح رابط النشر وأضف إليه:
?cashier=1

مثال: https://script.google.com/macros/s/رابط-النشر/exec?cashier=1

الواجهة تستخدم الدالة clientRequest الموجودة في كود قاعدة البيانات، لذلك يجب أن يكون ملف Code.gs الحالي نفسه داخل المشروع. سجّل الدخول باسم مستخدم وكلمة المرور الموجودين في ورقة Accounts.

الموجود في الواجهة:
- البحث بالاسم أو الباركود وإضافة المنتجات للسلة.
- الخصم، الدفع نقدًا أو شبكة، وحساب الباقي وطباعة إيصال.
- حفظ الفاتورة في Reports وتحديث المخزون في Products.
- عرض المنتجات والفواتير، وفتح/إغلاق الوردية.
- صفحة تقارير تعرض إجمالي المبيعات، النقد، الشبكة، الخصومات، الضريبة، المبيعات اليومية والأكثر مبيعًا.
- صفحة إعدادات لتعديل اسم المتجر والرقم الضريبي والهاتف والعنوان ورأس الفاتورة ورسالتها.
- صفحة حسابي لمتابعة الاشتراك والجهاز وعدد العمليات التي تنتظر المزامنة.
- كاش محلي للمنتجات والفواتير والورديات مع زر مزامنة يدوي.

ملاحظة الضريبة: تستخرج الواجهة الضريبة بنسبة 15% من الإجمالي عندما يحتوي حساب المتجر على رقم ضريبي، وإلا تعرض الضريبة صفرًا. أسعار المنتجات تعامل على أنها شاملة الضريبة. راجع إعداد الضريبة قبل الاستخدام الفعلي إذا كان تسعيرك مختلفًا.
